# free26

Готовая статическая PWA-сборка для челленджа free26. Код приложения находится в `index.html`; внешних сервисов и аккаунтов нет. Данные хранятся только в `localStorage` этого браузера. Для резервной копии используйте экспорт в Профиле.

В профиле можно записать цели периода, свои показатели и фото до/после. Фон каждой streak-панели меняется в «Профиль» → «Панели стиков». Раздел God хранит ежедневные отметки по 12 заповедям и 7 смертным грехам. Свайп по накоплениям прокручивает карточки; удалить карту можно из её меню.

## Публикация и установка на iPhone

1. Загрузите **всё содержимое** этой папки на статический хостинг с HTTPS. `index.html` должен открываться в корне сайта.
2. Откройте адрес сайта в Safari на iPhone и дождитесь первой загрузки приложения.
3. Нажмите «Поделиться» → «На экран Домой».
4. Запустите free26 с домашнего экрана. После первой загрузки приложение и локальные библиотеки будут доступны офлайн.

Для быстрого просмотра можно открыть index.html напрямую: интерфейс работает и без ES-модуля, если браузер блокирует локальные модули.

Иконка для iPhone берётся из `apple-touch-icon-v2.png` (фото franklin.jpg). Если free26 уже добавлено на экран Домой, удалите старый ярлык и добавьте сайт заново: iOS кэширует иконку отдельно от сайта.

Service Worker не запускается из `file://`; приложение нужно открыть через HTTPS (или localhost для разработки). Начальные даты: 09.11.2026–31.01.2027. Их можно изменить в Профиле.

Анимации anime.js 3.2.2 и Motion 12.23.24 включены локально в `assets/`, поэтому CDN после публикации не требуется. Лицензии библиотек находятся рядом с файлами.
